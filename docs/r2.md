# R2 開通與注意事項

## 1. 開通前先問：真的需要 R2 嗎？

| 想放的東西 | 不用 R2 的做法 |
|---|---|
| 網頁用的 JSON 快照、圖片、教材檔 | 當**靜態資源**跟 Worker / Pages 一起部署（免費、不限請求數） |
| 結構化資料 | D1 |
| D1 備份 | `wrangler d1 export <db> --remote --output backup.sql` 存本機 / OneDrive |
| 使用者上傳的附件（發票掃描、PDF） | **這個才需要 R2** |

沒有附件上傳需求，可以先不開。

## 2. 開通步驟

1. Dashboard 左側 → **R2 Object Storage** → 開通。
2. 會出現 **Activate R2** 付款頁：Apple Pay / Google Pay / PayPal / 信用卡擇一。
3. 頁面顯示 `R2 $0 / month`、`Due today $0`；免費額度：10 GB 儲存、Class A 100 萬次、Class B 1,000 萬次 / 月。
4. 完成後 `wrangler r2 bucket list` 不再出現錯誤碼 10042。

> **付款資訊一律由本人輸入**，不要交給 AI agent 或任何自動化工具代填。

## 3. 綁卡前後的差別

| | 未綁卡（只用 Workers Free） | 綁卡後的 R2 |
|---|---|---|
| 超過免費額度 | **服務停止**（請求失敗），不會扣款 | **自動計費** |
| 最壞情況 | 系統當天停擺 | 收到帳單 |

R2 是否提供「花到某金額自動停用」的硬上限，本文**未能查證**；啟用前請到 **Billing** 頁確認。

## 4. 防止意外扣款

1. **bucket 設為 private**，不要開啟 `r2.dev` 公開網址，也不要綁公開的自訂網域，除非確定要公開。
   費用失控最常見的原因是檔案被公開存取、被大量下載或爬蟲掃描（egress 免費，但 Class B 讀取次數會計費）。
2. **只經由 Worker 存取**，Worker 前面放 Cloudflare Access。
3. **Billing → Notifications** 設定帳單 / 用量通知（例如超過 US$1 即寄信）。
4. 用 **Standard** 類別；Infrequent Access 沒有免費額度、有取回費、最短計費 30 天。
5. 刪除物件（DeleteObject）免費；定期清掉不需要的檔案。
6. 不要建立權限過大的 R2 API Token（S3 相容金鑰）；需要時只給單一 bucket、設到期日。

## 5. 費用感受

以每月新增 5 GB 附件、一年累積 60 GB 估算：

| 時間 | 儲存費 |
|---|---|
| 前 2 個月 | $0（在 10 GB 內） |
| 一年後 | 約 (60 − 10) × $0.015 ≈ **$0.75 / 月** |

上傳次數 1 萬次 / 月遠低於 Class A 免費 100 萬次。
